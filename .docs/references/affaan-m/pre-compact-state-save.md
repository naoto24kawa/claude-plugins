# Pattern: PreCompact 状態保存

- **出典**: [affaan-m/everything-claude-code](https://github.com/affaan-m/everything-claude-code)
- **カテゴリ**: Hook 設計 / セッション管理
- **取り込み優先度**: 低

## 概要

コンテキストのコンパクション(要約圧縮)実行前に、現在のセッション状態をファイルに退避する。

## 仕組み

- `PreCompact` イベントで発火
- コンパクション発生を timestamp 付きでログに記録
- アクティブなセッションファイル (`*-session.tmp`) にマーカーを追記

## 設計の良さ

- コンパクションで失われるかもしれない重要な状態を外部ファイルに退避
- セッション再開時に「コンパクションが何回起きたか」が追跡可能
- 実装がシンプル (ファイル追記のみ)

## 適用先

長時間セッションを前提とするワークフローで有用。
