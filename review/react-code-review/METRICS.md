# React コードレビュー成功指標ガイド

## パフォーマンス指標

### レンダリングパフォーマンス

| 指標 | 良好 | 要改善 | 計測方法 |
|------|------|--------|---------|
| 初回レンダリング | < 100ms | > 200ms | React DevTools Profiler |
| 再レンダリング回数 | 1回/操作 | 3回以上/操作 | React DevTools |
| LCP (Largest Contentful Paint) | < 2.5s | > 4s | Lighthouse |
| FID (First Input Delay) | < 100ms | > 300ms | Lighthouse |

### バンドルサイズ

| 指標 | 良好 | 要改善 | 計測方法 |
|------|------|--------|---------|
| 初期バンドル | < 200KB | > 500KB | webpack-bundle-analyzer |
| コンポーネント単体 | < 10KB | > 50KB | Source Map Explorer |

---

## コンポーネント品質指標

### 設計指標

| 指標 | 良好 | 要改善 | 基準 |
|------|------|--------|------|
| コンポーネント行数 | < 150行 | > 300行 | 単一責任の目安 |
| Props数 | < 10個 | > 15個 | 複雑さの指標 |
| JSXネスト深度 | < 5階層 | > 8階層 | 可読性の指標 |
| 子コンポーネント数 | < 10個 | > 20個 | ファイル分割の目安 |

### 状態管理指標

| 指標 | 良好 | 要改善 | 基準 |
|------|------|--------|------|
| useState数/コンポーネント | < 5個 | > 10個 | useReducer検討 |
| useEffect数/コンポーネント | < 3個 | > 5個 | 副作用の複雑さ |
| Props伝播階層 | < 3階層 | > 5階層 | Context検討 |
| Context Provider数 | < 5個 | > 10個 | 設計見直し |

## アクセシビリティ指標

### Lighthouse スコア

| 指標 | 良好 | 要改善 | 基準 |
|------|------|--------|------|
| Accessibility スコア | 90+ | < 70 | WCAG AA準拠 |
| Best Practices | 90+ | < 80 | 一般的なベストプラクティス |

### 個別チェック項目

| 項目 | 必須 | 推奨 | チェック方法 |
|------|------|------|-------------|
| キーボード操作 | 全要素 | - | 手動テスト |
| フォーカス表示 | 全要素 | - | :focus-visible |
| alt属性 | 全画像 | - | axe DevTools |
| 色コントラスト | 4.5:1 | 7:1 | Lighthouse |
| heading階層 | 正しい順序 | - | axe DevTools |

## テスト指標

### カバレッジ

| 指標 | 良好 | 最低限 | 計測方法 |
|------|------|--------|---------|
| 行カバレッジ | > 80% | > 60% | Jest --coverage |
| 分岐カバレッジ | > 70% | > 50% | Jest --coverage |
| コンポーネントカバレッジ | > 90% | > 70% | 独自集計 |

### テスト品質

| 指標 | 良好 | 要改善 | 基準 |
|------|------|--------|------|
| テスト/コンポーネント比 | > 1.0 | < 0.5 | テストファイル数 |
| 平均テストケース数 | > 5個 | < 2個 | コンポーネントあたり |
| モック使用率 | < 30% | > 50% | 過剰なモックを避ける |

## shadcn/ui 準拠指標

### フォーム実装

| 項目 | 必須 | チェック方法 |
|------|------|-------------|
| Form コンポーネント使用 | Yes | コードレビュー |
| Zod スキーマ定義 | Yes | スキーマファイル存在 |
| FormField 使用 | Yes | コードレビュー |
| エラー表示統一 | Yes | FormMessage 使用 |

### スタイリング

| 項目 | 必須 | チェック方法 |
|------|------|-------------|
| セマンティックトークン使用 | Yes | bg-primary等 |
| cn() 使用 | Yes | クラス結合時 |
| ハードコード色なし | Yes | #xxx, rgb()の不使用 |
| ダークモード対応 | 推奨 | dark: プレフィックス |
