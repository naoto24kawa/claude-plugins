## 📋 レビューチェックリスト

### Root Route 設定
- [ ] `HeadContent` が `<head>` 内に配置されている
- [ ] `Outlet` が `<body>` 内に配置されている
- [ ] `Scripts` が `<body>` 内に配置されている
- [ ] `createRootRoute` を使用している

### Server Functions
- [ ] 入力バリデーション（Zod）が実装されている
- [ ] エラーハンドリングが実装されている
- [ ] 型安全性が保たれている
- [ ] 機密情報がサーバー側のみで使用されている

### データローディング
- [ ] `loader` を使用してデータフェッチング
- [ ] `beforeLoad` は認証チェックなど最小限の使用
- [ ] 並列実行可能なローダーは並列化されている
- [ ] ウォーターフォールが回避されている

### 認証とセキュリティ
- [ ] `beforeLoad` でルート保護を実装
- [ ] HTTP-only クッキーを使用
- [ ] CSRF 対策が実装されている
- [ ] XSS 対策が実装されている
- [ ] パスワードハッシュ化が適切

### 環境変数管理
- [ ] 機密情報は `process.env` を使用
- [ ] クライアント変数は `import.meta.env.VITE_*` プレフィックス
- [ ] `.env.local` が `.gitignore` に含まれている
- [ ] `.env.example` が提供されている

### 型安全性
- [ ] TypeScript strict mode が有効
- [ ] `any` 型の使用が最小限
- [ ] 型推論が正しく機能している
- [ ] `routeTree.gen.ts` が最新

### パフォーマンス
- [ ] `beforeLoad` は高速（認証チェックのみ）
- [ ] 重い処理は `loader` に配置
- [ ] プリロード戦略が設定されている
- [ ] コード分割が適切に実施されている
